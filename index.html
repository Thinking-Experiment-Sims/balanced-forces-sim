🧮 Solve for Hanging Mass from Measured Angles

2D Statics Force Diagram Model

ΣFx = T2·cos(θ₂) - T1·cos(θ₁) = 0

ΣFy = T1·sin(θ₁) + T2·sin(θ₂) - Fg = 0

The sum of upward vertical components supports the entire downward weight Fg = m·g.

Closed Vector Polygon (Tip-to-Tail)

ΣF⃗ = T⃗₁ + T⃗₂ + F⃗g = 0⃗

Because the knot is in static equilibrium, adding the force vectors tip-to-tail forms a closed triangle returning to the start point.
